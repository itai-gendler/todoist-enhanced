# Display preferences

The saved reading of one task page.

## Information kept

- **Page** — The page these choices belong to.
- **Mode** — List, board, focus, table or calendar where the page offers it.
- **Grouping** — How tasks on this page are grouped.
- **Sorting** — The selected ordering.
- **Filters** — Chosen workspaces, projects, tags, priorities, estimates and assignees, plus scheduled, subtask and completed-work inclusion.
- **Calendar** — Three-day, week or month presentation, forecast and completion inclusion.
- **Table** — Chosen columns and sorting presentation.
