# Comment

A task discussion entry with optional uploaded file details.

## Information kept

- **Text** — The comment’s Markdown text.
- **Posted on** — When it was posted.
- **Author** — The person who posted it.
- **Attachment** — Optional file name, size, type and external download location.
- **Reactions** — Emoji reactions and the people who made them.
